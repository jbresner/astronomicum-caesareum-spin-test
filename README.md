# Astronomicum Caesareum Spin Test

This is a test demonstrating how a digital version of the Astronomicum Caesareum might work. The Astronomicum Caesareum is an astrolabe published in 1540 by Petrus Apianus. The book has 21 volvelles, a rotating part of the physical book used to deterimine planentary positions. This test is an attempt to mirror the volvelles functionality in the physical book, which includes multiple volvelles on a single page including some that are interconnected.
